Deterministic Architecture

How Verdict Computes Truth

Instead of prompting an LLM to generate answers probabilistically, Verdict turns claim verification into an auditable graph computation in FalkorDB.

01 DECOMPOSE

Atomic Claims

Splits complex natural language into verifiable subject-predicate-object assertion triples.

02 RETRIEVE

Multi-Source Web

Live dual-tier crawling across Wikipedia, Wikidata, Google News RSS, and vetted fact-checkers.

03 INGEST

FalkorDB Graph

Constructs directed cyclic knowledge subgraphs with citation edges and PageRank source authority.

04 TRAVERSE

Cypher Proofs

Executes formal graph queries in FalkorDB's C engine to find load-bearing evidence paths.

05 VERDICT

Proof Dossier

Ranks proof paths by evidence weight and authority. Emits SUPPORTED, REFUTED, or abstains.

Epistemic Grounding

Why Epistemic Graphs Beat Raw LLMs

LLMs predict the most likely next word, not the truth. When asked about false claims, they confidently hallucinate convincing stories. Verdict replaces guessing with formal mathematical proofs.

The Black-Box LLM Problem

Probabilistic Next-Token Guessing

  • cancel Hallucinates with 99% confidence: Token likelihood correlates with fluency, not factual veracity.
  • cancel Zero verifiable proof trail: Cannot show an auditable mathematical chain of citations.
  • cancel Never abstains: Fabricates justifications rather than declaring lack of evidence.
The Verdict + FalkorDB Solution

Deterministic Graph Proofs

  • check_circle Formal Cypher graph traversals: Evaluated in C memory space. A claim is proven if and only if a path exists.
  • check_circle PageRank citation authority: High-authority domains (Snopes, UPI, Britannica) carry real epistemic weight.
  • check_circle Honest Epistemic Abstention: If evidence is missing or below threshold, Verdict yields UNVERIFIED.
